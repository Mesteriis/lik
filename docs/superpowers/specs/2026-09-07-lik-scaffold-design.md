# Lik: начальный каркас

Новый Android-проект галереи с ИИ. Текущий этап — сборка и стартовый экран, без логики галереи. По дополнительному запросу пользователя реализуется выбор иконки в настройках.

Референс: соседний `rune-keyboard`. Используем один модуль `:app`, Kotlin со встроенной поддержкой AGP, системные Android Views и JDK 17. Версии: AGP 9.2.1, Gradle 9.4.1, min/compile/target SDK 37, Build Tools 36.0.0. Поддерживается только актуальный Android 17, без совместимости со старыми версиями. Идентификатор — `io.github.mesteriis.lik`, версия — `0.1.0`.

Стартовая Activity содержит логотип пользователя, название, короткое описание и вход в настройки. Ресурсы поддерживают английский и русский языки, системную светлую/тёмную тему. Insets учитывают системные панели и вырезы. Все десять PNG используются без редактирования, adaptive icons получают безопасные отступы. Первая иконка — по умолчанию; выбор в настройках атомарно переключает launcher aliases и сохраняется средствами Android.

В каркас не входят MediaStore, разрешения на фотографии, сеть, модели, базы данных, сервисы или фоновые задачи. Пакеты для этих возможностей добавляются вместе с их реализацией.

Git remote: `git@github.com:Mesteriis/lik.git`. В репозитории находятся Gradle Wrapper, строгий lint, CI сборки, инструкция запуска и шаблон необязательной release-подписи. Проверка: debug/release APK, lint, компиляция instrumentation и запуск smoke-теста на API 37.
